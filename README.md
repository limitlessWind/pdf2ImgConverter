# pdf2ImgConverter
A lightweight tool for converting PDF files into JPG images.

## How to Use
Download **`pdf_to_image.html`** and open it directly in your browser.  
No installation required. Works on any platform.

## Background
Some applications require invoices or documents to be uploaded strictly as image files (JPG/PNG). However, many invoices downloaded from official websites come in PDF format. Most PDF-to-image converters available online either charge fees or place usage restrictions, making a simple task unnecessarily complicated.

With the assistance of modern AI tools—which are now powerful enough to automate this kind of conversion—I created a small, free tool to make PDF-to-image conversion fast and accessible for everyone.

The first version of this project was a Python script, later packaged into an executable file for easier distribution. 

The second version is a pure JavaScript implementation that runs directly in the browser, removing cross-platform concerns entirely.

## Features
- Convert PDF pages to JPG/PNG images in the browser  
- No backend, no upload — everything runs locally  
- Works on Windows, macOS, and Linux  
- Free and open source
